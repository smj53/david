# 요구 사항 분석 및 스프린트 계획 수립

## 1. 요구사항 분류

### 핵심 기능 (필수)
- 출발/도착 지점 입력 및 경로 추천(거리/시간 기준)
- 지도 상 경로 표시
- 실시간 데이터 활용
- 경로 추천 불가 시 사유 안내

### 비핵심 기능 (부가)
- 경로 요약/상세 정보 제공(텍스트/표)
- 실시간 도로 상황 정보 활용
- 이메일 공유/저장 기능
- 경유/회피 지점 지정 기능

### 기능 외 요구사항
- 도커 이미지로 결과물 제출
- 임의 지도 API 사용(사전 과제)
- 평가 기준(기능, 성능, 협업, 기술)

### 기타 사항
- 데이터 출처: 서울교통정보센터, 서울 교통 빅데이터 플랫폼
- 좌표계: 위경도(WGS80) 사용

## 2. 시스템 개발 참고사항

- 시스템 개발에 필요한 가정: 교차로는 모든 방향 진행 가능, 유턴 불가, 신호 대기 없음
- 용어 정의: 지점, 구간, 경로
- 지정된 데이터 출처: 서울교통정보센터, 서울 교통 빅데이터 플랫폼
- 기타: 사전 과제는 임의 지도 API 사용, 본과제는 차세대 지도 API 사용 예정

## 3. MVP 제품의 기능

- 웹 서비스 제공(파이썬 백엔드, JS/HTML 프론트엔드, 지도 API)
- 거리 기준의 최적 경로 추천 및 지도 표시

## 4. 스프린트 계획 (2주 단위, 총 4회, 8주)

| 스프린트 | 단계 요약 | 한 문장 요약 | 핵심 기능 | 비핵심 기능 | 주요 업무 |
|---|---|---|---|---|---|
| 1 | MVP 제품 개발의 준비 | MVP 제품 개발 준비 업무 수행 | 없음 | 없음 | 요구사항/시스템/데이터 분석, 데이터 확보, 기술 조사, 파이썬 클래스 설계 |
| 2 | MVP 제품 개발 | MVP 제품(거리 기준 경로 추천) 개발 | 거리 기준 경로 추천 | 없음 | 백엔드/프론트엔드 개발, 지도 연동, 경로 계산 기능 구현 |
| 3 | 경로 추천 기능 보완 | 경로 추천 기능 보완 및 확장 | 시간 기준 경로 추천, 실시간 데이터 활용 | 경로 요약/상세 정보, 경유/회피지점 | 실시간 데이터 연동, 기능 보완, UI 개선 |
| 4 | 서비스 개발 완료 | 서비스 완성 및 배포 준비 | 모든 필수 기능 | 이메일 공유/저장 등 | 테스트, 도커 이미지화, 문서화, 배포 준비 |

---

### 참고
- 전체 프로젝트 기간: 8주
- MVP 제품 개발: 4주 이내 완료
- 모든 요구사항을 스프린트 계획에 배치
